# Analog Input with LabJack U3 

This guide describes standard procedures for receiving *Analog Input* using the LabJack U3 in PsychoPy


**Prerequites**
These steps were already installed in 2056A and 2056B Stim computers

1. Install LabJack UD Software Windows Installer Package 
   (https://support.labjack.com/docs/ud-software-installer-downloads-u3-u6-ue9)

2. Install LabJack Support (LabJackPython) plugin PsychoPy/Tools/Plugin-Package Manager
